# Python Data Visualization Lab

A hands-on lab for exploring and visualizing data with Python.

## Learning Objectives
- Explore datasets using pandas.
- Create and customize charts with Matplotlib.
- Interpret data and save visualizations.

## Repository Contents
- `Data_Visualization_with_Python.ipynb` — Lab exercises
- `books.csv` — Dataset
- `requirements.txt` — Required packages

## Getting Started

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Open `Data_Visualization_with_Python.ipynb` and run the cells in order. Keep `books.csv` in the same directory.

## Activities
Data exploration, line charts, bar charts, scatter plots, histograms, and chart customization.

## Practice
1. Find the five most expensive books.
2. Experiment with histogram bins.
3. Create and save a chart as PNG.
